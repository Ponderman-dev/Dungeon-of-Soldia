# Difficulty curve and balance bots

Enemy growth, smart player, review/curve scripts.
Moved out of CLAUDE.md (2026-10-17). Keep this file up to date when the system changes.

- **Difficulty curve:** enemies attack 35% slower (`enemyAttackSpeedMultiplier` 0.65 in combat.json). Enemy stats rise every 3 floors: +50% health and +42% attack of base per step (ENEMY ADJUSTMENT 2026-10-20, user: floors 25-35 hit too hard; was +35% / +52.5%: more health, less attack = longer fights, fewer one-shots) (`floorScaling`, step floors = 3; linear, not compounding; floors 1-3 are base). Check the curve with `node scripts/tests/difficulty.mjs [speed] [hpPerStep] [attackPerStep]` (per-floor death %, health lost, fight length). Whole-game review: `node scripts/tests/review.mjs [runsPerSquad] [all|a,b,c]` plays every 3-hero squad like the balance bot (random items, skill books, golden book after bosses) and prints where runs end, boss win rates, fight length, hero/item/squad strength, page use, rules speed, stuck fights and errors (`balance.mjs` uses skill books too).
- **SMART PLAYER (difficulty curve work):** `scripts/tests/smartbot.mjs` (`playRun(squad, opts)`) plays whole runs like a thoughtful player: scores every reward card for every hero (`scoreFor()`: rarity, squad `needs`, damage type, damage items to the strongest attacker, defensive items to the front-liner, minion items to the summoner, skill items to skill heroes, +25% per copy already owned = keeps stacking), potions when hurt, books and pages (`GOOD_PAGES`, best skill spot), plays the special rooms, focuses boss objects then the weakest enemy. `opts.random` = the old random bot. `node scripts/tests/curve.mjs [runsPerSquad] [smart|random] [hpPerStep= attackPerStep= speed= heal=]` runs every squad on all CPU cores (worker_threads) and prints depth (mean/percentiles), survival curve, deaths per 5 floors, boss win %, killers, fight length, hero strength, rooms, most picked items. First result (5/squad): smart mean 36 / median 31 (random 31.5 / 29); almost nobody dies before 15, a wall at 16-20 (Grukk), steady losses 21-40, and squads that pass ~50 snowball to 100+ with SHORTER fights (heroes outscale the linear enemy growth). The smart player found a crash: a skill with no hittable target (only untargetable enemies left: Morthul dust, Vharox sky) hit `null`; now cancelled ('noTarget'), test `skill-no-target.test.mjs`.
- `node scripts/tests/dmgshare.mjs [runsPerSquad]` (session 5): smart-player runs to floor 80, each hero's damage split into basic / skill / other (items, passives) / minion by floor bracket (DoT ticks left out). First result: skills fall from 15-25% of a hero's damage early to 5-13% after floor 45 (items take over); Cleric, Alchemist and Mage skills hold; Bard's Discord is ~4% all run.
