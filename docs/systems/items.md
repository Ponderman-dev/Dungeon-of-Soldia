# Items

Item rules, icons, procs, stacking, every item batch. `docs/item-decisions.md` is the current truth for numbers and overrides older numbers here.
Moved out of CLAUDE.md (2026-10-17). Keep this file up to date when the system changes.

- **Item icons:** every item has a 16x16 pixel icon in `src/data/itemIcons.json` (`{ palette, rows }`, dark outline drawn in, centred), shown on the reward card inside a 20x20 frame whose colours tell the rarity (`rarities.json` `frame`: edge, fill, hi, stud = corner studs for epic/legendary). `framedIconPixels()` (systems/itemIcons.js, no Phaser), `itemIconKey(scene, id, rarity)` (entities/itemIconTexture.js) makes the texture; drawn at scale 3. Battle items and the hero-choice cards show these icons. Editable in the Character Studio (group "Item icons": a one-part character, part `icon`, doc id `item-<id>`); apply-designs.mjs writes kind `item` back into itemIcons.json. Tests: `item-icons.test.mjs`. Review page (all items + the user's notes; round 2 = db collection `notes2`, `_general` = general box): https://claude.ai/artifact/S7cbuLJoStsdi5hpg2SBef (`docs/proposals/item-review/`)
- **Special items (no negatives, epic/legendary):** Bulwark Plate (+defense, `thorns`: reflects % of melee damage taken), Siege Cannon (+attack, `skillDamage`), Bloodlust Mask (+attack speed, `lifesteal`), Gambler's Dice (+crit, `critDamage`). Trade-off items with negatives no longer exist.
- **Shield Totem (Block):** `block` special: 10% per totem (max 6) that a hit on the holder is stopped completely (rolled after evasion; no damage, no thorns/lifesteal). After a successful block ALL the holder's totems recharge for 2.5s (`cooldownMs` in the item; shown as a BLOCK CD tag, a `blockCooldown` status). Self scope, type special.
- **Proc rule (bug fix):** a proc only goes off (and pops its icon) if it can DO something: damage parts (extra hit, bomb, bolt, Excalibur tornado) go to the enemy nearest the hit one when the attack just killed it, and a tornado also comes on a miss; statuses on the target still need a live, hit enemy, otherwise the proc is skipped. Knife burst only with neighbours, Life Share only when an ally is hurt, tornadoes skip enemies that can't be hit. Checked by forcing every item's chance to 100% (tests in `items-g8.test.mjs`).
- **Proc items:** an effect can be `proc` (`proc`: trigger, so far only `onAttack` = each basic attack of the holder; `chance` %; `label`; `targets` self or squad; `apply` status specs). Every copy rolls separately. A proc buff from the same item refreshes instead of stacking. War Banner: 8% per attack of its holder, Battle Cry = whole squad +25% attack speed for 2s (replaced the old +8% attack).

- **Phase G items (G1-G8 done; list in docs/item-list.md, data in items.json):** the item JSON is data-driven: an effect is a stat (`stat` + `percent`/`flat`), a `damageBonus`, a `special` (numbers added up per copy into `hero.specials`; `unique` = value does NOT grow with copies, `cap` = total stops there, `falloffRatio` = diminishing copies, `below` = threshold), a `proc` (chance per attack; `falloffRatio` shrinks the chance of extra copies, `meleeOnly`, `unique`, `apply` with `scalesWithCopies`, `strike`, `chain`, `doubleHit`), `minionSpawner` or `greaterMinion`. Items may have `needs` (drop weight x0.25 without a source) and `provides` (tags: heroes.json `provides` and item `provides`: fire, ice, electric, dark, burn, poison, bleed, freeze, cc, shield, heal, beat, minion, taunt...). - **Item numbers:** defense, resist, evasion, crit items add FLAT points (+8 defense = 8% less physical damage). Attack and health items add a % of the hero's base stat.
- **Items on dead heroes:** ALL items on a dead hero stop working (squad-wide ones too). Dead heroes lose their gear for the run.
- **Boss stun/slow:** bosses take half-length stun and slow (value lives in the boss JSON).
- **Items are passive only:** never tappable or activatable. The player only taps skills and enemies.
- **Stacking:** no item has a max stack any more. An effect can have `falloffRatio`: each extra copy adds ratio^(copies-1) of the effect (used to creep towards a limit: Hourglass 0.95 -> 100%, Shield Totem 0.9 -> 100% block, Feather Boots -> 70 evasion, Echo Rune -> 90%). `perExtra`: the first copy gives the effect's value, each extra copy `perExtra` (Blood Chalice 20 then +10, Baton 25 then +8, Martyr 8 then +4, Mimic 10 then +3). A `unique` proc with `chancePerExtra` = ONE roll whose chance grows per extra copy (Hex Doll / Rusty Nails 8 +4, Dread Bell 5 +3, Jolly Banner 5 +3, Serrated Edge 10 +5); procs without `unique` roll once per copy. Status specs: `durationPerCopyMs` (per extra copy), `damagePerExtraPercent` (Ember burn +10%), `stackEach` (every application its own stack + timer: Hex Doll Curse, Rusty Nails Armor Break); `chain.jumpsPerExtra` (Static Crystal), `tornado.damagePerExtraPercent` (Excalibur).
