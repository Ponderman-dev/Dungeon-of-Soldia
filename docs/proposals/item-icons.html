Soldia item icons

A 16-pixel icon for every one of the 72 items, drawn in the same pixel style as the new characters. The frame around each icon shows its rarity, so a legendary is recognisable before you read anything.

Pick 1 reward
The object, not a symbolEach icon is the actual thing: a coin, a bell, a bomb with a lit fuse, a chest with teeth. No arrows or plus signs.
Colour tells the elementFire orange, ice pale blue, electric yellow, dark purple, poison green, blood red. The same colours the enemies and statuses use.
Frames tell the rarityCommon: plain grey. Rare: blue. Epic: purple with corner studs. Legendary: gold with corner gems and a slow shine.
Replaces the coloured dotOn the reward card the icon takes the place of today's type dot. Above the health bars in battle the small dots can stay, or become tiny 8-pixel versions later.

Shown at 4x (the game would show them at 2-3x). Every icon is a small grid of palette letters, so each one can be redrawn later the same way as the characters.
