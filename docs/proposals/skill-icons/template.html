Skill Icons

A pixel icon for every hero skill and passive, to replace the 2 letters on the fight buttons. Each is shown big and at about game size, in its button colour (red = attack skill, green = support skill, gold = passive). Below them: the skill book in one colour per page type. Mark each OK or CHANGE and write what you want different. Everything is saved for Claude.
