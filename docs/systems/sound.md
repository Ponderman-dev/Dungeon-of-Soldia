# Sound

sfx.js, cues, sound board and picks.
Moved out of CLAUDE.md (2026-10-17). Keep this file up to date when the system changes.

- `src/audio/sfx.js` (Web Audio, no Phaser): `sfx.play(cue)` plays a cue from `src/data/sounds.json` (cue -> file, volume, pitchJitter; `pack` = folder; `masterVolume`; `minGapMs`). Files are packed INTO the code with Vite `import.meta.glob(..., { query: '?inline' })` so the one-file preview page has them. Current pack: `src/assets/sounds/organic/` (uisfx 'organic', CC0, user's pick; licence in `src/assets/sounds/LICENSE-uisfx.txt`). Hooked: squad screen (tap, hero pick/back, card open/close, scroll, descend, unlock), reward sheet (up, each card, tap, item given, potion), battle (hero skill cast, interrupted, level up, floor cleared, defeat). A '♪ on/off' button on the squad screen (top right, under the test button) mutes; saved in progress `settings.muted`. A sound can never throw. Sound files are unpacked from their data: URLs with atob (`bytesOf()`), NEVER fetch(): the claude.ai preview frame blocks fetch, even of data: URLs (that made the game silent there).
- FIGHT SOUNDS (Kenney, CC0, user uploaded the packs; licence `src/assets/sounds/LICENSE-kenney.txt`): the chosen files are converted to small mono mp3 in `src/assets/sounds/kenney/` (a cue file name with a folder, `kenney/impactPunch_medium_000`, is read from that folder). A cue can list several `files` (a random take each time), a base `pitch`, `pitchJitter`, its own `minGapMs`; `maxVoices` 8 = most sounds at once. Hooked in BattleScene: a hit sound per damage type (`hitSound()`: hitMelee / hitRanged / hitFire / hitIce / hitElectric / hitDark / hitHoly) + crit, miss, block (also immune), shield soak / break, stun, freeze, enemy death, hero fall, minion summon, item proc (with the icon pop), boss intro (boss floor starts), boss wind-up warning, boss move, door opens on a win, footsteps on the door walks (`walkPath`), item given = coins. SOUND BOARD (round 2, user: 'too toyish, give 4-5 options each'): https://claude.ai/artifact/2pLgb918eNpVWUy2ePTSw8 = 5 options A-E per cue (A = game now; B-E layered / deeper / stone-room echo, built by `docs/proposals/sounds/make-options.py <kenney dir> <out>` with ffmpeg, peak-normalised), 'Try my own file' per cue and a MUSIC tester (local files, nothing uploaded; the user sends chosen files in chat), Kenney jingles, tips for the user's 7 GB GDC bundle. The user's PICKS are saved in the page's db (collection `picks`, doc = cue id, `{pick: 'A'..'E' | 'mine', file}`): read them with ArtifactData `list`, then copy the picked option mp3 into `src/assets/sounds/kenney/` and point the cue at it. Page built by `make-board.py <options dir> <jingles dir> <out.html>` from `board-template.html` (declares `db`). The USER'S OWN files (round 3: 23 Mixkit wavs from `sfx_1st.zip`; Mixkit free licence = OK in a game, no credit, but never ship them as a sound pack) are added as extra options F, G... (green letters) under the moments they fit by `add-yours.py <their files dir> <options dir>` (trim, length cap, fade, peak -1 dB; its MAP says which cues each file suits); it also adds rows for levelUp / potion / defeat (A = the Organic sound). Rebuild order: make-options.py, add-yours.py, make-board.py. APPLYING PICKS: `apply-picks.py <picks.json> <options dir>` copies each picked option to `src/assets/sounds/picked/<cue>.mp3` and points the cue at `picked/<cue>` (`source` = the option file; pitch is baked in).
